# Style: whiteboard lecture

A static "desk-cam" shot of a physical whiteboard, framed by its own aluminum bezel, on which a hand entering from the bottom-right corner writes, draws, underlines, circles, and erases with dry-erase markers and a block eraser — the classic hand-drawn whiteboard-explainer look. Everything is built stroke-by-stroke in real time rather than fading in, numbers get crossed out and replaced live, and nothing is ever fully wiped clean: every earlier section keeps ghosting through as a barely-visible watermark under the current one, giving the board a used, palimpsest-like texture. The mood is brisk, corporate-friendly, and a little playful (circled step numbers, a green checkmark shield, a red circled callout), riding a continuous, steady percussive beat underneath.

## Signature
| Item | On screen |
|---|---|
| Board & frame | Warm off-white board (`#F7F7F5`) with faint pre-existing gray cleaning-smudge arcs baked into the texture, bordered by a silver/gray beveled double-frame (`#B4B8C0` outer rim fading to `#F5F5F3` inner bevel) that reads as a physical whiteboard's aluminum edge |
| Hand & tool | A right hand + forearm in a navy sleeve (skin `#F0C3A2`, sleeve `#2F4A77`) enters diagonally from the bottom-right corner every time, holding whichever tool the beat calls for: a capped marker or a blue block eraser (`#2F5BD6`-ish body, gray felt base) |
| Ink palette | Black `#24262E` for headers/labels, blue `#1B4DC6` for new/updated values and taglines, red `#D5382B` for strikethroughs/alerts/circled callouts, green `#158A45` for a checkmark/safety icon, orange `#DE7426` used sparingly as the sole accent (title underline, one bar series, key stat) |
| Section slug | Each section opens with a circled sequential numeral (①②③) in black plus a short handwritten headline, top-left, drawn before anything else in that section |
| Data visuals | Hand-drawn bar charts: a wavy freehand baseline, solid rectangular bars (gray `#99A2AB` = before/old, orange = after/new), value labels hand-lettered above each bar in matching color, category label below in cursive |
| Comparison rows | "label : old value (red strikethrough) → new value (blue)" pattern, sometimes followed by a red hand-drawn circle/oval around a derived percentage |
| Ghost/echo layering | Every prior drawing persists as a near-transparent pale echo behind the current content instead of disappearing — the board never truly resets, it just gets fainter |
| Footer | A small gray italic handwritten citation line, bottom-left, present continuously as a running watermark/source credit |

## Direction
Create a whiteboard-explainer style video: a static, locked-off shot of a physical whiteboard inside a silver aluminum frame, warm off-white surface with faint pre-existing cleaning-smudge texture. A hand and forearm in a plain long sleeve enters from the bottom-right corner holding a dry-erase marker or a block eraser, and writes, draws, underlines, and circles content directly into frame with a simulated handwriting/drawing reveal (stroke order, not a fade-in). Use a small, consistent ink palette: black for headlines and neutral labels, blue for new/updated values or emphasis lines, red for crossed-out old values and alert callouts (circle or underline them by hand), green for a checkmark or positive icon, and one accent color (e.g. orange) reserved for a title underline and the "after" series in any chart. Open each new section with a circled sequential number plus a short handwritten headline at the top-left. Build any data as a simple hand-drawn bar or line chart with a wavy freehand baseline and hand-lettered value labels. Never fully erase the board between sections — let earlier content persist as a faint ghost/watermark behind the new drawing, and only use the eraser tool for small, localized swaps of a single value or word. Keep a small handwritten citation/footer line running continuously in a corner. Score it with a continuous, steady percussive beat with no silent gaps, optionally letting the beat's texture thin briefly at each section change to underline the reveal. Bookend the piece with a matching title-card layout (bold headline + colored underline + short tagline) at both the very start and the very end.
